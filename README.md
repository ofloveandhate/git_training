# git_training

A repository for training mathematicians on how to use Git.

The presentation in this repo is not reference material per se. It is intended for use as a presentation aid during a training session.  There is a lot which will go on via a projector and live demos.

## Schedule

* Session 1 -- Intro to git
* Session 2 -- Github basics, Branching and merging
* Session 3 -- Github, forking, issues, pull requests

## History

This was inspired by the ICERM semester on Nonlinear Algebra in Fall 2018, and used again in Fall 2019 at Illustrating Mathematics, and again in fall 2026 at MPI-CBG
